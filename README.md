# drone-stuff

Reverse engineering and documentation of the DJI DUML v1 protocol used by
a WM260-series aircraft, plus two from-scratch client implementations.

See the `duml-protocol-work` branch for the actual content: protocol
reference docs, a Python library, and a C++ library.

This repo does not contain any DJI firmware files. The source firmware
images used during analysis are proprietary and are not redistributed
here — only the original documentation and code produced from studying
them.
